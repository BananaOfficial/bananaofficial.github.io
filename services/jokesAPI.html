Documentation

GET/api/jokes/

Returns one random joke by default.

ParameterValuesPurpose
idnumberReturn one specific joke.
categorytextFilter jokes by category.
randomtrue / falsetrue returns one random match; false returns all matching jokes.

Examples

/api/jokes/ — random joke

/api/jokes/?id=1 — joke #1

/api/jokes/?category=programming — random programming joke

/api/jokes/?category=programming&random=false — all programming jokes

POST/api/jokes/

Adds a joke to the database.

ParameterPurpose
categoryJoke category.
setupThe setup/question.
punchlineThe answer/punchline.
authorName or label of the author.
