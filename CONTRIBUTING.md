# Contributing

Want to contribute? Cool.

## How to contribute

1. Fork the repository.
2. Make your changes.
3. Test them.
4. Open a pull request explaining what you changed and why.

## Guidelines

- Keep changes relevant to the website.
- Keep the code readable.
- Don't add malicious, broken, or unnecessary code.
- Check that links and pages still work.
- Be respectful.
